# Phase 1: watchOS Recording Prototype

Date started: Not started

## Goal

Build the smallest possible watchOS app that proves Apple Watch can act as a
reliable capture surface.

## Scope

Required:

- Create iOS app plus watchOS companion app in Xcode.
- Request microphone permission.
- Start recording from the watch.
- Stop recording from the watch.
- Save the audio file locally.
- Show recording, idle, and error states.

Optional:

- Pause and resume.
- Show elapsed time.
- Add one quick tag.

Out of scope:

- iPhone transfer.
- Transcription.
- Summary generation.
- Cloud upload.
- Multi-platform support.

## Completion Criteria

Phase 1 is complete when:

- The watch app can record and stop without crashing.
- A recording file exists after stop.
- The recording file can be played back or exported for validation.
- Known limitations are documented in this file.
